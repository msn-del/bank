# gestion-comptes

Bank account management program in C, using a singly linked list.

## Features

- Add an account (number, holder name, initial balance)
- Delete an account
- Search for an account and view its balance
- Display all accounts
- Make a transaction (deposit or withdrawal)

## Compile and run

```bash
gcc main.c -o comptes
./comptes
```

## Example

```
===== GESTION DE COMPTES BANCAIRES =====
1. Ajouter un compte
2. Supprimer un compte
3. Rechercher un compte (voir le solde)
4. Afficher tous les comptes
5. Effectuer une transaction (depot/retrait)
0. Quitter
```

Type the number of the option you want, then follow the instructions.
